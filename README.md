# qq_praise — QQ 名片点赞插件

给 bot 一个"点赞"工具，**让 bot 自己决定给谁点赞、给不给、什么时候给**。

插件向 bot 提供一个 `praise_user` 动作（LLM 可调用工具）：有人 @ 求赞 / 求互赞 / 让你点赞时，或者 bot 自己想感谢、回应某个人时，由模型自主决定是否调用。是否给、怎么回应完全由各自的人设决定——傲娇、温柔、高冷、毒舌都能直接用，插件不预设任何话术。

插件不做关键词匹配、不做定时/事件自动触发、不在群里转述——"给不给、怎么说"全部交给模型。

---

## 功能特性

- **LLM 自主决定**：不是"检测到求赞就自动点"，而是把点赞能力作为工具交给模型，让角色自己判断
- **自适应分批**：单次批量优先 20，被服务端拒绝（如 OIDB 1001）自动降级到 10 重试；50 赞 = 20+20+10
- **真人节奏**：分批之间随机等待 2~5 秒（可配置），不会一秒打满
- **24h 冷却**：同一个人每天只点一次；冷却中调用会把"已点过"如实返回给模型
- **好友/非好友区分**：可分别设置赞数；非好友点赞需要 bot 账号开通 SVIP
- **黑名单**：配置不点赞的 QQ 号
- **真实结果反馈**：成功几个、部分成功、失败原因、冷却中、被跳过——全部如实返回给模型，由它用自己的口吻转述，不允许假装没点

## 安装

1. 下载 Release 里的 `qq_praise-x.y.z.mfp`
2. 放进 Neo-MoFox 的 `plugins/` 目录
3. 重启 bot，看到 `✅ 插件加载成功: qq_praise` 即完成

不需要额外 Python 依赖。

## 配置

网页管理端 → 插件配置 → qq_praise，或直接编辑 `config/plugins/qq_praise/config.toml`。

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `plugin.enabled` | `true` | 是否启用插件 |
| `behavior.stranger_like_enabled` | `true` | 是否尝试给非好友点赞（需 SVIP，普通账号会被拒并记日志） |
| `behavior.friend_times` | `20` | 给好友每次点赞的个数（1~50；SVIP 每人每天上限 20，非 SVIP 服务端按 10 截断） |
| `behavior.stranger_times` | `50` | 给非好友每次点赞的个数（1~50，需 SVIP） |
| `behavior.like_interval_seconds` | `[2.0, 5.0]` | 分批之间的随机间隔秒数；两个值相同则固定间隔；设 `[0, 0]` 关闭等待 |
| `behavior.cooldown_hours` | `24` | 对同一个人的点赞冷却（小时），0 表示不冷却 |
| `behavior.blacklist` | `[]` | 不点赞的 QQ 号列表 |

## 使用方法

### 自动触发（推荐）

装好即用。当群聊/私聊里出现这些情况时，模型会自己判断要不要点：

- 有人 @ bot 或说"给我点个赞""互赞一下"
- 有人夸 bot、感谢 bot，bot 想回礼
- 角色人设本身"想宠某人"的时候

示例对话：

> 用户：`@妮卡 给我点个赞`
> 妮卡：`哼，就这一次。`（调用了 `praise_user`，返回"已为 xxx 点赞 20 个"）

> 用户：`谢谢妮卡今天陪我`
> 妮卡：`记得就行。`（顺手点了赞）

### 手动触发

对 bot 说"给 QQ 号 123456 点个赞"即可，`target` 参数支持：

- **纯数字** → 按 QQ 号处理
- **昵称/群名片** → 插件会在当前群成员里自动解析成 QQ 号

### 不想让她点

直接说"别点"，或者把人加进 `behavior.blacklist`。

## 已知 QQ 规则（实测）

- 单次 `send_like` 上限 20；超过 50 会整单被拒（OIDB 1001）
- 好友每人每日点赞上限：非 SVIP 10 个 / SVIP 20 个，超出部分服务端拒绝后自动降级分批
- 每日点赞总量有上限，超出报 OIDB 20003，插件会停在真实值并告知模型
- 非好友点赞是 SVIP 特权，普通账号会被拒（插件只记日志，不报错）

## 兼容性

- 需要 Neo-MoFox 核心（自带 `default_chatter`）
- 需要 `onebot_adapter`，且协议端实现 `send_like`（NapCat / LLOneBot / SnowLuma 等）
- 插件版本：`1.0.0`；插件 API 版本：`1.0.0`

## 常见问题

**Q：为什么她有时候不点？**
A：点赞是模型自主决定的，不是必触发。想让她点，可以直接要求，或调整人设里对待求赞的态度。

**Q：点了但显示失败？**
A：看返回的原因——常见是"今日点赞达上限""非好友需要 SVIP""冷却中"。插件会把真实原因告诉模型。

**Q：会不会太频繁被风控？**
A：冷却 24h + 批间随机 2~5 秒 + 单次上限 20，已经是比较保守的节奏。担心的话把 `friend_times` 调低、`like_interval_seconds` 调大。

**Q：能在其他 MoFox 分支/其他框架用吗？**
A：本插件基于 Neo-MoFox 插件系统（`src.app.plugin_system.*`）编写，其他框架需要改适配层。
